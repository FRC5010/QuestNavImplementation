# Test setup

This procedure sets up the floor reference for QuestNav accuracy tests. Do it one time
for each test area.

## Equipment

- Plumb bob (a string with a weight)
- Tape for the floor, or a chalk line
- Tape measure
- Laser line level (optional)

## Procedure

1. Mark the point below the tag:
   1. Hang the plumb bob from the center of the tag.
   2. Let the plumb bob become stable.
   3. Put a mark on the floor where the plumb bob touches.

   Use this mark as the reference, not the base of the stand. Then the distance between
   the tag and the board does not have an effect on your measurements.

2. Put a centerline on the floor:
   1. Run a tape line or chalk line from the floor mark, straight out from the tag face.
   2. Make sure that the line is square to the tag. Use one of these methods:
      - **3-4-5 triangle:** Measure 3 ft along the base of the stand and 4 ft out along
        the line. The diagonal between the two points must be exactly 5 ft.
      - **Laser line level:** Align the laser line with the floor mark and make it
        square to the tag face.

3. Put cross lines on the centerline at 1 m, 2 m, 3 m and 4 m from the floor mark.
   These lines are only visual guides. Measure the exact values for each test.

4. Tape the feet of the stand to the floor.

> **Caution:** If the stand moves, all measurements after that are incorrect. If someone
> hits the stand, do this procedure again.
