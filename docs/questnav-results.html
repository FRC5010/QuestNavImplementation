Absolute accuracy

Tag 24 is not at its official position, so QuestNav anchored badly (run 1) or not at all (run 2). A measured hallway layout fixes this for run 3.

QuestNav tracks the robot's motion well. When the robot turns in place, its position stays within a few millimeters. With no tag in view for a minute, it drifts up to about 5 cm. We do not yet know how close QuestNav puts the robot to its true field position. That is the most important question for match use. The hub tags cannot be moved, so we measured where they are and made a hallway field layout. With that layout on the headset, run 3 can answer it.

Correction (Nov 23): the first version of this report gave a Drift Loop error of 4.4 cm RMS (maximum 9.3 cm). Part of that was error in the truth itself: the positions of two robot tags were poorly known. The tool now fits them from the whole session, and the corrected Drift Loop error is 2.0 cm RMS (maximum 4.6 cm).

How we measured

Two cameras on tripods filmed each session. A laptop tool finds the AprilTags on the hub and on the robot in every frame and calculates where the robot really was (the truth), to a few millimeters. A sync wiggle (±30° turns) at the start and end of each routine lines up the video clock with the robot log. The tool then compares truth with the QuestNav pose in the log.

Errors are reported two ways:

  • Aligned: the QuestNav path is first moved and turned as one piece to fit truth. This shows steadiness and drift. It is valid even when QuestNav is not anchored to the field.
  • Absolute: QuestNav minus truth in field coordinates. This is what an auto depends on. It is valid only when QuestNav is anchored to the field correctly.

Run 3 checklist

Before

  1. Upload the hallway field layout (src/main/deploy/apriltag/hallway-5010.json) on the QuestNav web page, select it, and restart QuestNav. Do not move or re-tape any hub tag; if one moves, the layout must be measured again.
  2. Measure the robot tags 1–4: each center's distance forward and left of the robot center, its height, and the direction its face points. Measure the black square.
  3. Record a new Akaso calibration video: board propped still, camera on a tripod, no ceiling-light glare, pause at each spot. The GoPro calibration passes; keep its settings.
  4. Charge the headset to 100%. Deploy the robot code from questnav-tag-distance.

Setup

  1. Headset: Airplane mode on, QuestNav open, team 5010, hallway layout selected. Check networkConnected is true with curl -4. On the dashboard, questnav/Field Layout shows the hallway file.
  2. Cameras 2.0–2.5 m high, about 90° apart, pointed down at the test area. Each one must see at least 2 hub tags (the Akaso: tag 24 and tag 25 or 26). Akaso date stamp off.
  3. Confirm anchoring: robot 2 m out from tag 24, right side toward the corner, wait 5 s. questnav/Distance To Target Tag must match a tape measurement within 5 cm. Do not start until it does.
  4. Optional: tape floor tags 50–52 flat in the test area and measure them from tag 24.

During

  1. Start both cameras, then step away. Keep people out of the camera views.
  2. Leave Test/Settings/Sync Wiggle on.
  3. Run each routine 3 times: Turn Sweep, Drift Loop (30 s, then 60 s and 150 s), Stop At Marks.
  4. Repeat the Drift Loop at Max Speed 1.5 m/s.
  5. Write down what happened and when, especially anything unusual.

After

  1. Copy the robot log from the roboRIO and the videos into tools/groundtruth/sessions/run3/.
  2. Run tag detection and the session analysis. Keep the laptop lid open; detection takes about as long as the video.
